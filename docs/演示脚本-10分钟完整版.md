# 生涯罗盘 · 演示脚本（10 分钟完整版）

**开场定位语（务必先说）**：这是一款**县域高中生的生涯探索工具**——让每一所中学的学生，都能获得科学的生涯探索支持。

**演示前准备**：
1. `npm run dev` 启动，浏览器开好首页；
2. 提前把「演示模式」开关打开，准备好"还没想好选科的高一学生"人设；
3. 备好报告页整页截图与桑基图截图，网络或时间紧张时备用。

---

## 0:00–1:00 开场 + 定位（首页）

- 一句话价值主张：`让每一所中学的学生都能获得科学的生涯探索支持`。
- 讲清"为什么是县中"：2024 年我们对山东、河南两所县中高一学生（n=2119，男 968/女 1151）施测了职业决策因素量表（胡洁 2007 改编版），发现"不清楚所选科目以后能做什么"是突出的未决原因——所以我们把**学科→选科→专业→职业路径**做成了报告核心，而不是只给一个职业列表。
- 指向首页右侧的 **CIP 金字塔**：整个产品的模块划分，直接对应认知信息加工理论（自我知识 + 职业知识 → 决策技能 → 元认知）。

## 1:00–2:00 走一遍流程（知情同意 → 基本信息）

- 知情同意：强调**未成年人友好**——"这不是考试、不能替你做决定、数据只在本机、随时可删"。
- 基本信息：不采集学校、姓名、联系方式；只有昵称（本机识别）、年级段（12–14 / 15–16 / 17–18 三段，对应 Super 发展阶段）、性别与地区类型（可选）。

## 2:00–3:00 测评大厅 + 演示填充

- 展示 7 个模块卡片：暖场 + 兴趣/能力/价值观（P0 核心）+ 适应力/决策（P1）+ 人格（P2），每个卡片带一句理论依据。
- 说明"快速模式"：只做暖场 + 三核心模块，约 6 分钟。
- 打开演示模式，**一键填充"还没想好选科的高一学生"**：这个人设兴趣分化度低、对"科目通向哪里"了解不足、有一定担心——正是调研里的典型画像。

## 3:00–4:00 作答页体验（抽 1–2 题）

- 展示兴趣模块第 1 题：指导语"你喜欢做这件事的程度"；5 点量表**支持键盘 1–5 直接作答**、Enter 下一题。
- 展示能力模块：指导语"**你有多大信心做好这件事？**"（Bandura 自我效能标尺措辞），0–100 十档滑条。
- 一句话点出设计差异：能力模块测的是"信心"不是"能力"，信心可练，低分只说明还没练到。

## 4:00–6:00 报告核心区块（重点）

1. **生涯画像卡**：默认人设是"兴趣图谱较为均衡 · 探索期"——注意这里**没有大字三码**，因为它的兴趣分化度低，我们不做"过早定向"（这是伦理承诺，v1.0 Identity 设计）。
2. **兴趣六边形 + 兴趣×能力四象限**：四象限是全场最出彩的一块——"喜欢 ≠ 擅长"，成长区（喜欢但还不熟练）才是干预价值最高的地方。
3. **学科→选科→专业→职业桑基图**：直接回应调研痛点，把"今天的课堂"连到"将来的职业"；选科节点带政策脚注（临床医学、药学依据《指引（通用版）》教学厅函〔2021〕27 号）。
4. **职业匹配推荐**：每个职业给"为什么匹配"三条理由（兴趣 40% / 能力 35% / 价值观 25%），可展开，讲可解释性。

## 6:00–8:00 决策技能 + 行动计划 + 叙事

- **决策风格**：GDMS 五风格 + CASVE 五步引导式提问——不只给标签，而是"带你走一遍决策流程"。
- **生涯适应力 4C**：关注/控制/好奇/信心，每项低分配一个可落地的练习（Savickas：适应力可训练）。
- **行动计划**：近/中/远三层，每条都能追溯到"依据哪个模块哪个维度"。
- **生涯叙事小结**：第二人称讲述"你的故事"，结尾"这是此刻的样子，不是结论"。

## 8:00–9:00 伦理与合规（评委必问）

- 报告页脚固定免责声明 + 12355 温和提示；任何页面/导出不含学校、姓名等身份信息。
- 打开「关于 → 心理测量学仪表盘」：顶部**显眼标注"模拟数据 · 方法演示"**，展示 Cronbach α 与兴趣六型相关矩阵，诚实说明计算链路与局限。
- 局限性声明：自编/改编条目未经标准化信效度检验；演示常模非全国常模。

## 9:00–10:00 收尾

- 复盘一句话：**"测评不是算命，是把选择权还给学生的工具。"**
- 开放 Q&A（预判问题：信效度、常模来源、纯前端数据安全、与选科政策的衔接）。
