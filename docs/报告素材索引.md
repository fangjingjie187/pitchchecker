## 二、数据素材入口

### 2.1 心理测量学结果表
- **文件**：`docs/心理测量学结果表.md`
- **内容**：Cronbach α（各模块）+ 兴趣六型相关矩阵，标注「模拟数据 · 方法演示」
- **生成命令**：`npm run psychometrics`
- **原始模拟样本**：`src/data/sampleResponses.json`（200 份，种子随机离线生成，非真实数据）

### 2.2 暖场常模实测锚定参数（n = 2119）
- **实现位置**：`src/data/norms.ts`（`BASE_NORMS.warmup` + 文件头注释有完整换算说明）
- **关键参数**：
  - 样本：2024 年山东、河南两所县域普通高中高一学生，n = 2119（男 968 / 女 1151），量表为职业决策因素量表（胡洁，2007）高中生改编版
  - **换算公式**：原始 5 点量表 → 0–100 尺度：`mean' = (M − 1) / 4 × 100`，`sd' = SD / 4 × 100`
  - `clarity`（定向清晰度）：M = 2.76 → 44；SD = 0.64 → 16
  - `comfort`（担心程度）：正向 M = 3.17 → 54，但滑条方向为「担心程度」须反向映射 `100 − 54 = 46`；SD = 0.92 → 23。⚠ 报告勿直接写 54
  - `information`（信息充足度）：**无实测锚定**，预估参考值 40/20
  - 仅 **15–16 段**有实测锚定，12–14 / 17–18 段由 `BAND_ADJUST` 外推（无独立实测）
- **界面脚注**：`WARMUP_NORM_NOTE`（`src/config/app.config.ts`），暖场作答页底部展示

### 2.3 RESEARCH_CONTEXT 字段
- **位置**：`src/config/app.config.ts`（`RESEARCH_CONTEXT`，约第 101–111 行）
- **字段**：`year: 2024`、`description`（样本描述）、`instrument`（量表名）、`n: 2119`、`male: 968`、`female: 1151`
- **展示处**：About 页「理论与伦理 → 前期调研」卡片
