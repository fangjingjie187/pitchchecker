## 第二部分 · 价值观迫选计分映射说明

### 2.1 为什么混入迫选题

评定题容易出现「全都选重要」，看不出排序；迫选题逼出真实取舍，也能降低社会赞许性偏差。

### 2.2 选项 → 维度映射

### 2.4 合成规则

```
评定分 p = (作答值 − 1) / 4 × 100            # 1–5 点线性映射到 0–100，仅 7 个维度有
迫选分 f = 该维度被选中次数 / 该维度在迫选题中出现次数 × 100

             只有评定题时直接取 p；只有迫选题时直接取 f
```
