# 生涯罗盘 · 演示脚本（3 分钟精简版）

**开场定位语（第一句）**：这是一款**县域高中生的生涯探索工具**——让每一所中学的学生都能获得科学的生涯探索支持。

**演示前准备**：已启动 `npm run dev`，演示模式已开启，报告页与桑基图截图各就位。

---

## 0:00–0:30 定位（一句话 + 一个数字）

- 一句话：县域高中生的生涯探索工具。
- 一个数字：2024 年两省县中高一学生 **n=2119** 实测发现，"不清楚所选科目以后能做什么"是最突出的未决原因。

## 0:30–1:30 从"一键填充"到报告

- 测评大厅 → 演示模式 → **一键填充"还没想好选科的高一学生"** → 生成报告。
- 边等边说：7 个模块按理论骨架分层（P0 兴趣/能力/价值观 → P1 适应力/决策 → P2 人格），全部落在 CIP 金字塔上。
- 落在报告首页：**"兴趣图谱较为均衡 · 探索期"**——不显示大字三码，因为我们不做过早定向。

## 1:30–2:30 三个核心亮点（图说话）

1. **学科→选科→专业→职业桑基图**：直接回应"学这些以后能干什么"，把今天的课堂连到将来的职业。
2. **兴趣×能力四象限**：喜欢 ≠ 擅长；成长区（喜欢但还不熟练）才是最值得投入的地方。
3. **职业匹配的理由**：不给你冷冰冰的分数，每条都告诉你"为什么"（兴趣 40% / 能力 35% / 价值观 25%）。

## 2:30–3:00 收尾（伦理 + 一句话）

- 伦理：报告页脚固定免责声明 + 12355 温和提示；无身份信息；条目为自编/改编、演示常模非全国常模（诚实披露）。
- 一句话收束：**"测评不是算命，是把选择权还给学生的工具。"**
